This repository contains the code, experiments, and datasets associated with the paper *"Mitigating Model Drift in Developing Economies Using Synthetic Data and Outliers"*, accepted as a poster at the **[NeurIPS 2025 Workshop on Generative AI in Finance](https://openreview.net/forum?id=zfTaFD0B5Z)** (peer-reviewed on OpenReview).

- **Paper (OpenReview):** https://openreview.net/forum?id=zfTaFD0B5Z
- **Preprint (arXiv):** https://arxiv.org/abs/2510.09294
- **Dataset (Hugging Face):** https://huggingface.co/datasets/zyplai/stabilization-uplift
- **Metrics package (PyPI):** [`pip install stabilization-uplift`](https://pypi.org/project/stabilization-uplift/)
- **Metrics calculator and `evaluate` module (Hugging Face Space):** https://huggingface.co/spaces/zyplai/stabilization-uplift

The research focuses on stabilizing machine learning models in finance against distribution shifts and sudden macroeconomic shocks in developing economies by leveraging synthetic outliers.

## Repository Content

- **Notebooks and scripts** for generating synthetic outliers, training models, and evaluating stability.
- **Datasets**:
  - Preprocessed open dataset: [Lending Club](https://www.kaggle.com/datasets/wordsforthewise/lending-club)
  - Synthetic data with and without outliers generated by [zGAN](https://arxiv.org/abs/2410.20808).
- **Metrics**:
  - Stabilization Score (SS) – measures relative performance drop under shocks normalized by covariate drift.
  - Stabilization Uplift (SU) – weight-adjusted metric for comparing two models pre and post-shock.
  - Both metrics are published on PyPI as the [`stabilization-uplift`](https://pypi.org/project/stabilization-uplift/) package.

> **Note:** The paper also reports experiments on proprietary financial datasets from Central Asia and the Caucasus (Tajikistan, Uzbekistan, Kazakhstan, Azerbaijan). These datasets are confidential and are not included in this repository; only the experiments on the open Lending Club dataset can be reproduced from it.

## Metrics Package

The SS and SU metrics are published on PyPI as the [`stabilization-uplift`](https://pypi.org/project/stabilization-uplift/) package, so you can use them in your own projects without this repository (source in [`package/`](package/)):

```sh
pip install stabilization-uplift            # SS and SU
pip install "stabilization-uplift[shift]"   # + distribution_shift computed from data
```

```python
from stabilization_uplift import stabilization_score, stabilization_uplift

stabilization_uplift(auc_base_A=0.80, auc_shock_A=0.70, auc_base_B=0.80, auc_shock_B=0.81, dist_shift=0.2)
```

The metrics can also be tried in the browser in the [calculator Space](https://huggingface.co/spaces/zyplai/stabilization-uplift), which is also a Hugging Face `evaluate` module: `evaluate.load("zyplai/stabilization-uplift")`.

The [package page on PyPI](https://pypi.org/project/stabilization-uplift/) has an end-to-end example on the Hugging Face dataset, a guide to interpreting SS and SU, and the API reference.

## Key Contributions

1. **Stability metrics for model drift evaluation under shocks**  
   Introduces a two-level evaluation framework (SS and SU) to quantify model performance under sudden distribution shifts.

2. **Synthetic outliers for model drift mitigation**  
   Demonstrates that carefully generated synthetic outliers improve model stability when combined with real and synthetic data.

3. **Focus on developing economies**  
   Experiments are conducted on datasets from markets where macroeconomic shocks are frequent and unpredictable.

## Project Structure

- `1 pre-processing & research.ipynb` — data preprocessing, exploratory analysis, saving prepared datasets.
- `2 experiments_on_open_data_catboost.ipynb` — experiments with CatBoost on open data.
- `3 experiments_on_open_data_tabpfn.ipynb` — experiments with TabPFN on open data.
- `4 experiments_on_data_stability_other_models.ipynb` — data stability and experiments with other models (LightGBM, NGBoost, TabNet, etc.).
- `artifacts/` — experiment results (csv files).
- `data/` — preprocessed and synthetic data.
- `src/` — utility scripts and modules.

## Quick Start

Requires **Python 3.11+** and Jupyter.

1. **Clone the repository with Git LFS** (the `.parquet` data files are stored in Git LFS):
   ```sh
   git lfs install
   git clone https://github.com/zypl-ai/stabilization_uplift.git
   cd stabilization_uplift
   git lfs pull
   ```

2. **Install dependencies:**
   ```sh
   pip install -r src/requirements.txt
   ```
   `src/requirements.txt` lists the packages used in the experiments with their versions. The full Google Colab environment used for the paper is saved in `src/requirements-colab-freeze.txt` for reference.

3. **Run Jupyter from the repository root** (the notebooks use paths relative to it):
   ```sh
   jupyter notebook
   ```
   Open the desired notebook and follow the cell instructions. On Google Colab, `cd` into the cloned repository folder before running the notebooks.

Notebooks 2–4 use the preprocessed data already included in `data/`, so notebook 1 does not need to be re-run to reproduce the experiments. Re-running notebook 1 downloads the raw Lending Club data via `kagglehub` (requires a Kaggle account) and fetches macroeconomic features from FRED, which requires a free [FRED API key](https://fred.stlouisfed.org/docs/api/api_key.html) passed to `add_macro_features_fixed(..., api_key=...)`.

## Data Description

The data is also available on Hugging Face as [`zyplai/stabilization-uplift`](https://huggingface.co/datasets/zyplai/stabilization-uplift) and can be loaded without Git LFS:

```python
from datasets import load_dataset

real = load_dataset("zyplai/stabilization-uplift", "lending_club", revision="v1.0")
synthetic = load_dataset("zyplai/stabilization-uplift", "synthetic", revision="v1.0")
```

- `data/preprocessed/` — Lending Club data after cleaning, enriched with macroeconomic features, split into base train, base test and shock test sets.
- `data/synthetic/` — synthetic training data generated by zGAN, without outliers (`synth_lending_club.csv`) and with different proportions of synthetic outliers (`synth_lending_club_out<proportion>.csv`).

## Experiments

- Comparison of various models ([CatBoost](https://arxiv.org/abs/1810.11363), [TabPFN](https://www.nature.com/articles/s41586-024-08328-6), [LightGBM](https://proceedings.neurips.cc/paper_files/paper/2017/file/6449f44a102fde848669bdd9eb6b76fa-Paper.pdf), [NGBoost](https://arxiv.org/abs/1910.03225), [TabNet](https://ojs.aaai.org/index.php/AAAI/article/view/16826), [HGBoosting](http://jmlr.org/papers/v12/pedregosa11a.html), [XGBoost](https://dl.acm.org/doi/10.1145/2939672.2939785), [FT-Transformer](https://arxiv.org/abs/2106.11959)).
- Analysis of model stability to data changes.
- Results are saved in the `artifacts/` folder.
